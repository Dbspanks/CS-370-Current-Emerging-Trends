# CS-370-Current-Emerging-Trends
Portfolio Reflection for Pirate Intelligent Agent Project
For this project, I worked with the starter code provided in the TreasureHuntGame Jupyter Notebook and the accompanying Python files that defined the game environment, state space, and reward structure. The starter code handled the map layout, movement rules, and rendering of the pirate’s interactions within the grid world. My responsibility was to complete the Q‑training algorithm section of the notebook. I implemented the deep Q‑learning logic, including the neural network model, the epsilon‑greedy exploration strategy, the replay memory, and the training loop that allowed the pirate agent to learn how to navigate the environment and reach the treasure. I also added comments and structure to make the code readable and maintainable.

This project helped me connect the course material to the broader field of computer science. Computer scientists design systems that solve real problems, and reinforcement learning is one example of how computational methods can be applied to decision‑making tasks. The work matters because intelligent systems are becoming part of everyday life, and understanding how they learn, adapt, and behave is essential for building reliable technology. Throughout the course, I learned to approach problems by breaking them down into smaller components, identifying constraints, and iterating on solutions. In this project, that meant understanding the environment, defining the agent’s goals, and choosing the right learning strategy to achieve those goals.

Completing this project also reinforced the ethical responsibilities that computer scientists have to both users and organizations. When designing intelligent systems, it is important to consider how the model behaves, how transparent its decisions are, and whether it could produce harmful or biased outcomes. Even in a simple game environment, the principles of responsible AI still apply. As a developer, I need to ensure that the systems I build are understandable, safe, and aligned with user expectations. This includes writing clear documentation, testing thoroughly, and considering how the system might fail or be misused. These responsibilities carry forward into any future work I do in machine learning or software development.
